E02 讲过 API 响应里 usage 三兄弟的计数方式，这一课把计数换成钱——把同一项任务的三种实现方案摆上账单台，看成本到底花在哪里。上方的三张账单对应同一个客服答复任务：A 方案一段话加随便写，B 方案结构化 prompt 加短输出，C 方案在 B 的基础上让稳定前缀命中缓存。三张账单回答同一个问题：同样的效果，钱花在哪、省在哪。看完这三笔账，「成本」就不再是一个财务名词，而是和延迟、准确率并列的设计参数。

## 账单公式：两行算术

API 计费公式只有两行：输入 token 数 × 输入单价，加输出 token 数 × 输出单价。各家定价页的表格再复杂——阶梯价、包月、批量折扣——折算到单次调用都是这两行；对账时拿响应里的 usage 字段逐项乘单价，就能复现出账单上的每一分钱。结构上最要紧的事实是：输出单价通常是输入的数倍——示例账单里输入 ¥4/M、输出 ¥16/M，差 4 倍。原因在算力：读入的 token 在预填充阶段一次并行处理就完事，输出的 token 却要逐枚串行生成，每一枚都是一次完整的前向计算。所以「让模型少说」往往比「让模型少读」更省钱——这个比例关系决定了后面所有优化手段的排序。

## 输出成本无法预先精确

输入长度在发出请求前就定了，输出长度却只有生成完才知道——「想到哪写到哪」的生成过程决定了输出成本不可预先精确，只能预估。这不只是财务上的小麻烦：预算、限流、对外报价都依赖「单次调用大概多少钱」，估不准就会要么超支要么亏本。实用的预估做法有三条：用历史调用的输出均值当估计值，再用百分位（如 P95）兜住长尾偏差；按业务给输出设上限（max_tokens），把最坏情况钉死；对结构化任务用格式声明压住输出长度，让「最多多长」变成可设计的参数。B 方案的 reply 不超过 80 字就是这一招——输出从 1600 压到 450 token，不是靠运气，是靠把长度写进约束。要强调的是：预估错了不可怕，可怕的是没有上限——没有 max_tokens 兜底，一次异常的长回答就能击穿按次核算的预算。

## 三张账单的算术

把三张账单并排算（构造口径：10 万次调用/天、30 天月、示例费率输入 ¥4/M、输出 ¥16/M）。A 方案：输入 900 + 输出 1600，单次 ¥0.0292，月约 ¥87,600。B 方案：输入 1500 + 输出 450，单次 ¥0.0132，月约 ¥39,600——格式声明让输入多花几百 token，输出省下的钱却远多于输入多花的，这正是「输出贵 4 倍」的直接推论。C 方案：输入 1500 中 1200 命中缓存按十分之一价折算 + 输出 450，单次 ¥0.00888，月约 ¥26,640。三案对比：B 比 A 每月省 ¥48,000，C 又比 B 省 ¥12,960，C 合计比 A 省 70%。再看清楚一点：三张账单用的是同一个模型、同一种单价，任务与效果也相同——省下的钱没有一分来自「换更便宜的模型」，全部来自「少生成」与「命中缓存」这两个工程动作。

## 杠杆排序与模型差异

同任务不同模型的单价可以差出几十倍，换模型当然是一张牌，但它是最后一张：能力、窗口、嵌入维度都要重新评估，切换还有迁移成本——R 模块课讲过换嵌入模型等于全库重嵌的代价。日常工程里杠杆按性价比排序是：第一，缓存——把稳定不变的前缀（system、格式声明、知识库索引）逐字节固定，命中部分按大幅折扣计费，命中率决定省钱幅度；第二，精简输出格式——结构化短输出同时改善成本与时延；第三，控制上限——max_tokens 钉死最坏情况。三招都指向「少生成」同一个方向。还有一个常被忽略的杠杆在系统之外：很多任务根本不需要每次调用都带大前缀，把「哪些请求值得带知识库、哪些一句话就够」想清楚并路由开，比任何计费技巧都省。

## 成本意识从第一行代码开始

成本不是上线后才补的报表，而是从第一行代码就该带着的意识：每次调用的响应里都带着 usage 回执，把回执聚合起来，才有「谁在花钱、花在哪」的账。这本账是 G02 成本工程课的地基——那一课会把「改造前与改造后」的账单、预算与看板展开。本课带走的习惯有三条：需求评审时把「这个功能的单次调用成本」当验收项，和延迟、准确率一起写进验收标准；写 prompt 时把输出长度写进约束，让成本在源头可设计；新功能先小流量跑几天，看 usage 分布里输入输出的真实比例，再决定放量还是先优化。

## 演示数据说明

本页三张账单中的 token 数、费率与金额均为教学构造值：输入 ¥4/M、输出 ¥16/M、缓存命中按输入价 1/10 折算皆为示例口径，非任何厂商报价；「10 万次调用/天、30 天月」为构造的量级假设。单次成本按「输入 token × 输入费率 + 输出 token × 输出费率」计算，账本卡片中的「输入成本」为该组输入侧速算值。真实价格以各厂商官方定价页为准。
