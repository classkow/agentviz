上一课跟随一次请求走完了从浏览器到 GPU 的全程，这一课放大其中最基础的计量单位：token。上方的解剖台把六段常见文本摆上手术台——同样是一段「字」，中文、英文、代码、emoji 切出来的 token 数可以差出几倍，而计费与上下文窗口占用都按 token 计。

## 模型眼里的文字：token，不是字符

模型并不直接读写字符，它处理的是 token——tokenizer 先把文本切成词表里的条目，每个条目对应一个整数编号，模型看到的其实是编号序列。主流切分算法 BPE（字节对编码）的原理一句话可以说完：从单个字节出发，反复把语料中出现频率最高的相邻对合并成一个新条目，直到词表达到预定规模；于是高频词整体成一枚 token，生僻词和长词则被拆成词根甚至字节。由此记住两个关键事实：模型生成文本时是一个 token 一个 token 往外吐的，API 计费也是按 token 逐枚计价的——token 是生成与计费共同的计量单位。词表装不下的生僻字符是 BPE 的边界情形：切分会一路退化到字节级，一个罕见字符可能拆出好几枚。这也解释了为什么同一套模型面对不同语言待遇不同——词表按训练语料的频率分布训出来，语料里少见的文字，切分天然吃亏。

## 切分差异：中英、代码与 emoji

同一段字数，token 数可以差几倍，上方演示的六组对照就是证据。中文没有空格充当天然边界，常按 1\~2 个汉字一枚切分；英文高频词大多一词一枚，长词则被拆成词根。中英混排时，语言切换处容易蹦出孤立的单字 token，账面消耗常被低估。代码的 token 密度最高：标识符、缩进与标点各自成 token，短短两行调用就能吃掉几十枚。最贵的反而是 emoji——界面上最「轻」的一个字符，账单上常占 2\~3 枚。想省 token，先盯住代码片段、长单号和 emoji 密集的内容。中英混排的孤字问题有具体成因：tokenizer 按最长匹配贪心切分，语言切换处的汉字常常匹配不到成词条目，只能单独成枚。代码密度高也可以细分原因：关键字与常见库名因高频而成整枚，缩进、括号与分号却各有各的 token，一行嵌套调用拆出的枚数远超它的视觉长度。

## 两张账单：计费与上下文窗口

API 响应的 usage 字段里有三兄弟：prompt_tokens（输入）、completion_tokens（输出）、total_tokens（合计）。计费时输入输出分开计价，输出费率通常是输入的数倍——让模型「少说」往往比「少问」更省钱。另一张账单是上下文窗口：窗口里装的是对话全部历史消息的 token 总和，每发一轮新请求，都要为所有历史 token 重新付一次输入费。DeepSeek 文档给过粗糙换算口诀：1 个中文字符约 0.6 个 token，1 个英文字符约 0.3 个——这类口诀只配用来估预算量级，准确值永远以响应里的 usage 为准。重复付输入费的机理正是无状态：服务端不保存会话，每轮请求都把全部历史重新 tokenize 一遍、重新计一次 prompt_tokens——轮数越多，为同一段历史付的次数越多。输出更贵也有成本根源：生成是逐 token 串行的，每枚输出都要过一次完整的前向计算，而输入可以并行预填充，单位算力成本天然不同。

## 控制成本：从文本卫生开始

成本控制的第一道闸门是 max_tokens：给输出设上限，并检查响应里的 finish_reason——若值为 length，说明生成是被硬截断而非自然结束，答案多半不完整，需要调大上限或拆分任务。第二道是文本卫生：订单号、时间戳这类可由程序生成的标识符留在代码侧拼接，不要喂进 prompt——长数字串会被逐段切开，纯属浪费。第三是去冗余与结构化：删掉寒暄和重复背景，用清晰的结构标记替代散文式描述，往往能在不损失效果的前提下把输入 token 明显压下一截。finish_reason 为 length 的典型场景是长文摘要：输入一篇长文要求总结，max_tokens 设小了，模型写到一半被掐断，结尾往往缺结论。另一个常见浪费是把程序能算的东西写进 prompt——让模型逐字复述长 ID、念出订单号，既贵又容易错，这类字段在代码侧拼回即可。

## token 与工程决策

token 意识会直接改写工程决策。估上下文预算时，要把系统提示、历史消息、检索片段和输出余量一起算进窗口，再为突发留缓冲；窗口不是「能用多少算多少」，超出的请求会被直接拒绝。流式输出的首字延迟也与 prompt 的 token 数挂钩——输入越长，预填充越慢，首字越迟，这是长上下文场景体验变差的根源之一。这条链路和前后课程正好接上：E01 里 prefill 决定首 token 延迟，耗时与输入 token 数直接挂钩；E03 讲生成端从概率分布里抽签，抽出的每一枚都在为 completion_tokens 计费；E04 回答窗口装不下时怎么办——截断、摘要与取舍，前提都是先会算这本 token 账。下一课 E03 采样实验室已经上线，讲生成端如何从候选 token 的概率分布里抽签；再往后的 E04 会讲上下文与记忆，回答「窗口装不下时怎么办」。
